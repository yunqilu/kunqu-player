# Realize each explicit dieqiang code as a repeated score note

Each `d` in Gongche Raw will create one same-pitch repetition of the preceding main note in the canonical score interpretation, partially replacing ADR-0009's name-only fallback for dieqiang. The repetition count and pitch are `derived` from the explicit codes; duration is independently `derived` when confirmed metered context and canonical allocation determine it, or `inferred` in free meter or uncertain context. MusicXML keeps a green “叠腔” (diéqiāng, the repeated-note ornament) label on the originating note, while playback rendering may alter articulation but cannot invent further repetitions.
