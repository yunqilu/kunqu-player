# Realize explicit duoqiang as stop, rest, and carry

Each `c` in Gongche Raw denotes 掇腔; 撮腔 and the website identifier `cuoqiang` remain accepted aliases. The canonical score interpretation will realize it as a time-bearing “顿—休—带” sequence: the preceding written note is the half-beat solid stop, a quarter-beat rest follows, and the next written note is the quarter-beat light carry. The structure, rest existence, and `2:1:1` proportion are `derived` from the reviewed rule, while concrete onset and duration retain the evidence status of their metered or free-meter context. Explicit ban-yan anchors on either written note take precedence over the proportion and are never moved to satisfy it. If the proportion conflicts with those anchors but a positive-duration rest still fits, the converter retains the stop-rest-carry structure, marks affected concrete onset and duration values `inferred`, and reports `DUOQIANG_ANCHOR_CONFLICT`. If no positive-duration rest can fit, it retains the original written notes and green qiangge label, emits neither a zero-duration nor grace rest, marks the local realization `unresolved`, and reports `DUOQIANG_NO_METRIC_SPACE`. A rest with uniquely derived metered placement is rendered normally in black; inferred placement or duration is orange, and the rest is never purple because it belongs to the canonical score rather than playback rendering.

Neither parsing nor realization requires a preceding breath code, a particular lexical tone, or phrase-exit placement; those are traditional usage descriptions rather than validity predicates. The carry remains a normal-sized, black, time-bearing score note rather than a cue or grace note. The visible green “掇腔” label and `other-ornament` attach once to the `c`-bearing stop note; the rest and carry share its `realizationId` without repeating the label, which remains present even when realization is unresolved. Resolution may cross `gc` tokens and lyric characters to select the next written pitch, but only within the same confirmed phrase and qupai section; a confirmed phrase or section boundary stops the search. A carry selected across a lyric boundary continues the preceding lyric through a MusicXML lyric extension, and the displaced lyric may attach only to a later non-carry main note in its own remaining Gongche range. If none exists, the converter keeps that lyric as an orange review word, reports `DUOQIANG_LYRIC_COLLISION`, and leaves all later lyrics in place rather than cascading displacement. If no eligible following note exists, the converter preserves the qiangge label and reports `DUOQIANG_MISSING_TRAILING_NOTE` without copying the preceding pitch. Consecutive `c` codes after the same preceding note realize only the first code and report `DUPLICATE_DUOQIANG_CODE` for the remainder; they do not create multiple rest-carry groups. Gongchepu.net's same-pitch half-weight insertion remains an optional playback-compatibility effect and cannot modify the canonical MusicXML note structure. This decision partially replaces ADR-0009's name-only fallback for `c` and ADR-0011's metric-gap-only origin for canonical rests.
