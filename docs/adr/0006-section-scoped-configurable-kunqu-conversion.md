# Scope musical context by qupai section

Tuning, banshi, and related reading context will be attached to qupai sections and resolved through versioned conversion profiles rather than whole-score defaults or title-specific converter branches. The reviewed *Xunmeng* score is the first fixture, not the domain boundary, because the same converter must support many Kunqu scores whose tuning and meter can change at different section boundaries.

Each normalized section materializes its full context using explicit section notation first, documented profile inheritance second, and best-effort inference last. Carry-forward is never an unconditional global behavior, so omitted headings can express traditional shorthand without silently spreading one score's assumptions into another.
