# Map default banshi cycles to explicit MusicXML meter

The default profile maps liushui to 1/4, one-ban-one-yan to 2/4, one-ban-three-yan to 4/4, and its added-ban form to 8/4 grouped 4+4, while sanban uses senza misura. Per-score profiles may override these choices, and no mapping implies tempo; using quarter-note units keeps each ban or yan as one addressable beat and makes anchor validation straightforward.
