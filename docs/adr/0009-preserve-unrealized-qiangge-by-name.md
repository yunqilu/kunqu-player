# Preserve qiangge by name until its realization is reviewed

The breath code `/` maps directly to a MusicXML breath mark, while `h`, `s`, `d`, and `c` map to visible named other-ornaments unless a versioned profile supplies their exact pitch and timing realization. This keeps the confirmed meanings—huo, sou, die, and cuo—visible without inventing Western notes from a performance instruction that is not itself a complete micro-melody.
